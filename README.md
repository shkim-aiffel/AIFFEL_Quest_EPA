# AIFFEL_Quest_EPA

- AIFFEL 캠퍼스 기업 프라이빗 AI 과정의 퀘스트(프로젝트, 피어리뷰) 수행 결과물을 모아둔 레포지토리입니다.

- 각 폴더 최하위에는 프로젝트 코드와 함께 피어 리뷰를 위한 PRT(Peer Review Template) 기반 `README.md`가 포함되어 있습니다.

## 레포지토리 구조

```
AIFFEL_Quest_EPA
├── DL                  # 머신러닝과 딥러닝(Deep Learning) 기초 모듈의 퀘스트
│   └── DL01
│       └── README.md
├── NLP                 # 자연어 처리(Natural Language Processing) 기초 모듈의 퀘스트
│   ├── NLP01
│   │   └── README.md
│   ├── NLP02
│   │   └── README.md
│   ├── NLP03
│   │   └── README.md
│   ├── NLP04
│   │   └── README.md
│   └── NLP05
│       └── README.md
└── LLM                 # LLM(Large Language Model) 모듈의 퀘스트
    ├── LLM01
    │   └── README.md
    ├── LLM02
    │   └── README.md
    └── LLM03
        └── README.md
```


각 퀘스트 폴더(`DL01`, `NLP01` ~ `NLP05`, `LLM01` ~ `LLM03`)는 하나의 프로젝트 단위이며, 프로젝트 진행 후 결과물(노트북, 코드 등)이 추가됩니다.

## 피어 리뷰 (PRT)

각 퀘스트 폴더의 `README.md`는 AIFFEL 피어 리뷰 템플릿으로, 아래 항목을 기준으로 리뷰를 진행합니다.

1. 주어진 문제를 해결하는 완성된 코드가 제출되었는가
2. 핵심적이거나 복잡한 부분의 주석/doc string을 보고 코드가 잘 이해되는가
3. 디버깅 기록 또는 새로운 시도·추가 실험이 있는가
4. 회고가 잘 작성되었는가
5. 코드가 간결하고 효율적인가 (PEP8 준수, 함수화/모듈화 등)
